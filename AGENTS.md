# Branches e propostas

Por orientação do proprietário do projeto, todo novo trabalho deve criar uma branch a partir da proposta mais recente, preservando suas alterações. Consulte o head atual dessa proposta no GitHub antes de começar; não use uma cópia antiga de main como base.

Enquanto as propostas anteriores estiverem abertas, abra a nova proposta com a branch da proposta imediatamente anterior como base, para apresentar apenas a nova etapa. Registre a dependência na descrição da proposta. Quando as anteriores forem integradas, ajuste a base para main conforme necessário.

Por orientação posterior do proprietário, todas as novas branches devem começar com o número sequencial da etapa/proposta, seguido de um nome descritivo (ex.: 21-protecao-notificacoes-push), para permitir identificar a ordem. Preserve também a regra de partir da proposta mais recente.
